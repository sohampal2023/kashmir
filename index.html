TravelSafe Kashmir

Consent-based travel check-ins, shared location, and safety alerts

Safety note: This website is not an emergency dispatch service. For immediate danger in India, call 112. Location sharing works only after permission and may stop when the browser/device is suspended.

1. Account

Not signed in.

Each person should use their own account. Do not share passwords.

2. Trip and access

Sign in, then enter the trip code.

A trip code is an identifier, not a secure invitation by itself. Firebase database rules must restrict access to authorised users.

3. Check-in

Expected check-in interval: 1 hour.

First alert after 3 missed check-ins. Serious escalation after another 30 minutes without a check-in. Repeated escalation: every hour.

Join a trip to enable check-ins.

A real missed-check-in watchdog must run on a trusted server or scheduled backend. This page alone cannot reliably run alerts if it is closed.

4. Location sharing

Location is shared only when the traveller chooses to start it. Stop it whenever you want.

Location sharing is off.

5. Optional camera preview

Camera access is explicit and local preview only. This page does not transmit video to the controller.

Camera is off.

6. Quiet hours

Quiet hours are a display preference only in this website. A server-side watchdog must independently enforce a sleep schedule if alerts are to pause reliably.

Default quiet hours: 11:00 PM to 7:00 AM.

7. Safety contacts

India emergency number: 112

Jammu & Kashmir Police: verify current local contact details before travel. If there is immediate danger, call 112.

Email alerts notify the chosen recipients only. They do not verify danger or automatically dispatch emergency services.

Privacy: do not use covert tracking. Share trip details and location only with informed, authorised people. A website cannot guarantee that all copies of emails, browser records, logs, or backups are erased.
